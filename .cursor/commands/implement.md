# /implement — Простая задача

**Когда использовать:** компонент, функция, эндпоинт, небольшой use case.

## Workflow

1. **Worker** — создаёт код + базовые тесты (если есть тестовый фреймворк)
2. **Test-Runner** — запускает `npm run lint`, `npm run build`, проверяет работоспособность
3. **Documenter** — добавляет JSDoc/комментарии, обновляет документацию при необходимости

## Как выполнять

1. Прочитай задачу пользователя
2. Вызови логику Worker: создай код, соблюдая Clean Architecture (см. ARCHITECTURE.md)
3. Запусти линтер и сборку
4. Добавь краткую документацию (JSDoc, README при необходимости)

## Связь с агентами

- Используй @worker для создания кода
- Используй @test-runner для проверки
- Используй @documenter для документации

## Пример

```
/implement Создай use case getExpenses в application/useCases/expenses/
```

Результат: use case + проверка линтом/сборкой + JSDoc.
