# Task Management

Управление задачами в оркестрации.

## Формат задач

- `⏳` — ожидает
- `🔄` — в работе
- `✅` — выполнено
- `❌` — отменено

## Идентификаторы

Используй префиксы: `AUTH-001`, `EXP-002`, `UI-003` и т.д.

## Файлы

- Планы: `docs/plans/` (если включено)
- Workspace: `.cursor/workspace/` (временные метаданные, не коммитить)

## Обновление статусов

При переходе задачи в работу — меняй ⏳ на 🔄. По завершении — 🔄 на ✅.
