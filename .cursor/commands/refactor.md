# /refactor — Безопасный рефакторинг

**Когда использовать:** код работает, но плохо организован. Нужно улучшить структуру без смены поведения.

## Workflow

1. **Senior-Reviewer** — находит code smells, цели рефакторинга
2. **Refactor** — применяет изменения (без смены поведения)
3. **Test-Runner** — lint, build, проверка
4. При падении → **Debugger**
5. **Documenter** — отчёт об изменениях

## Важно

Тесты/линт должны существовать до рефакторинга. Если нет — сначала `/implement` для добавления проверок.

## Как выполнять

1. Senior-Reviewer анализирует код
2. Refactor вносит изменения
3. Test-Runner проверяет
4. Documenter фиксирует изменения

## Связь с агентами

- @senior-reviewer — анализ
- @refactor — изменения
- @test-runner — верификация
- @debugger — исправления
- @documenter — отчёт
